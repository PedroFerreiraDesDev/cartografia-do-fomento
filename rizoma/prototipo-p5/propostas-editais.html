Três formas para os gráficos dos editais

O autor não gostou das barras do valor dos editais e da disputa. Aqui estão três propostas, desenhadas em p5.js com os dados reais dos doze editais, para escolher. Cada uma parte de uma referência e fica dentro da linguagem do site: papel, três tintas, bolinha e grão de spray. Passe a mão ou toque em cada desenho.

PROPOSTA A

Muro de blocos

Todo o dinheiro dos editais vira um muro. Cada bloco é um edital, e o tamanho do bloco é o valor. Os quadrados escuros dentro de cada bloco são os projetos de grafite deste corpus, na mesma escala.

REFERÊNCIAMcCANDLESS, David. The Billion Dollar Gram. Information is Beautiful. Ideia emprestada: valores como retângulos encaixados, lidos pelo tamanho. RESPONDEQuanto cada edital ofereceu, e que parte foi para estes projetos. COMO LERCada faixa é um mecanismo. Dentro da faixa, cada bloco é um edital, do mais antigo em cima ao mais novo embaixo. Bloco grande, edital grande.

Passe a mão ou toque num bloco.

BOM PARAVer de uma vez o tamanho de tudo e como a parte do corpus é pequena. Não precisa de eixo.
LIMITENão mostra a disputa. Comparar dois blocos de formatos diferentes é menos exato que comparar barras. O LMIC 2023 - IF fica de fora, porque o edital não fixa valor.
PROPOSTA B

Bolinhas: tamanho e disputa

Cada edital é uma bolinha, a mesma do mapa. O tamanho é o valor do edital. A altura é a parte dos inscritos que foi aprovada. As bolinhas escuras dentro são os projetos deste corpus. Um desenho só responde às duas perguntas.

REFERÊNCIAMcCANDLESS, David. Snake Oil Supplements e World's Biggest Data Breaches & Hacks. Information is Beautiful. Ideia emprestada: bolhas em que o tamanho é uma medida e a posição é outra. RESPONDEQuanto cada edital ofereceu, quantos inscritos passaram e onde estão os projetos do corpus. COMO LERDa esquerda para a direita, os anos. De baixo para cima, a parte dos inscritos que foi aprovada: quanto mais baixa a bolinha, mais disputado o edital. Bolinha grande, edital com mais dinheiro. Contorno tracejado quer dizer dado incompleto.

Passe a mão ou toque numa bolinha.

BOM PARAJuntar os dois gráficos num só e usar a bolinha, que é a marca do site. Mostra que edital grande não quer dizer edital fácil.
LIMITETamanho de círculo se compara pior que comprimento. Pede dois eixos, então precisa de mais explicação. Em 2017 a Prefeitura só publicou a disputa somando Fundo e Incentivo Fiscal.
PROPOSTA C

Peneira

Cada grão é um projeto inscrito. Os grãos caem numa peneira: os aprovados passam e ganham a tinta do mecanismo, os outros ficam em cima, em cinza. É o spray do site usado para contar gente.

REFERÊNCIANEURATH, Otto. International picture language: the first rules of Isotype. London: Kegan Paul, 1936. Ideia emprestada: mostrar quantidade repetindo uma marca, uma para cada unidade, em vez de esticar uma barra. RESPONDEDe quem se inscreve, quantos passam. O valor do edital entra como número, embaixo de cada peneira. COMO LERCada quadro é um edital. Grãos cinza em cima da linha: inscritos que não passaram. Grãos coloridos embaixo: aprovados. Dá para contar.

Passe a mão ou toque num quadro.

BOM PARASentir a disputa: mil grãos em cima, cem embaixo. Cada grão é um projeto de verdade, o que conversa com o grão do spray.
LIMITENão compara bem o valor dos editais. Ocupa mais espaço. Só o desenho não basta para o valor: ele vai escrito.

O que eu recomendo

A proposta B, sozinha, no lugar dos dois gráficos de barras. Ela responde às duas perguntas, usa a bolinha do mapa e é diferente de tudo que já está nos Indicadores. A peneira, proposta C, pode entrar como detalhe: ao tocar numa bolinha, os grãos daquele edital caem.
