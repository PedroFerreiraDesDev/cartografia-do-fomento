## Como editar no Illustrator
1. Abra o SVG diretamente no Illustrator.
2. Use o painel Camadas/Objects para localizar grupos por ID (nav, project_hero, chart_region etc.).
3. Textos permanecem como texto SVG editável.
4. Retângulos, linhas, círculos e paths são vetores.
5. Substitua placeholders de imagem pelos registros reais quando disponíveis.
6. Não transforme “A verificar” em dado numérico sem fonte documental.
7. Exporte de volta como SVG mantendo IDs quando o arquivo for usado no site.

## Lógica do protótipo
Descobrir → clicar em muro → página dedicada do projeto.
Indicadores → hover mostra projetos → clique fixa o recorte → projeto abre a mesma página.
Editais → mecanismo → projetos.
Pesquisa → dados agregados; sem inferir classe social a partir de região.
